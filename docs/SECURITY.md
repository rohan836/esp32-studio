# Security

- Never upload a firmware image when compilation failed.
- Do not guess a board profile from chip family alone when flash layout matters.
- Keep downloaded tools in app-private storage.
- Do not execute downloaded scripts automatically.
- Keep arbitrary shell execution behind the terminal screen.
- Show the exact command and exit status for advanced actions.
- Do not store Git tokens in project files.
- Validate archives before extraction.
- Use HTTPS for package downloads and remote builds.
